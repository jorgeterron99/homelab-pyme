# Certificaciones recomendadas

Ordenadas según el retorno esperado para un perfil de sistemas y redes junior. Confirma siempre precios, formato y vigencia en la web del fabricante antes de inscribirte.

| Certificación | Para qué sirve | Cuándo |
|---|---|---|
| AZ-900 (Azure Fundamentals) o AWS Cloud Practitioner | Base cloud; suele pedirse como mínimo | Durante las fases 1-3 |
| CCNA | Estándar de redes, muy reconocida | Después de la fase 2 |
| LPIC-1 / RHCSA | Linux demostrable | Tras las fases 4-6 |
| Fortinet NSE 1-3 (cursos gratuitos) | Seguridad y firewalls en pymes | En cualquier momento |
| AZ-104 / AWS SAA | Siguiente paso en cloud | Cuando ya tengas el nivel base |
| SC-900 / Security+ | Base en seguridad | Opcional |

## Consejos
- No acumules certificaciones sin práctica; el repo y las certificaciones se refuerzan mutuamente.
- Haz los laboratorios oficiales y los simulacros de examen.
- Prioriza una certificación cada 2-3 meses.
